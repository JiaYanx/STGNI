# STGNI: Spatio-Temporal Graph Node Importance for Software-Defined Networking Traffic Prediction

The repository contains the datasets used by the STGNI model. 

The '01 source file' directory includes the source files downloaded from SNDlib(https://sndlib.put.poznan.pl/home.action). 

The '02 processing dataset' directory contains source-target-demandValue data extracted from each XML file. 

The '03 dataset' directory includes data that has been standardized for each node.

The '04 result' directory includes result that has been standardized for each node.
